type: feedback

Documentation, commit messages and PR descriptions must be written in English. GitHub Issues must be managed in Italian. Working session interaction language is Italian.

**Why:** User preference for clear separation between project artifacts (English, for international audience) and direct collaboration/issue tracking (Italian, native language).

**How to apply:** Before writing any commit message, PR body, or code comment — use English. Before creating/commenting on GitHub Issues — use Italian. When chatting with the user — always Italian. Diagrams in documents must use Mermaid syntax. GUI mockups must be produced as Draw.io files.
