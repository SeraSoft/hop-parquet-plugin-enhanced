# Apache Hop Enhanced Parquet Plugin

## Overview

This plugin is an enhanced version of the Parquet plugin currently available [Apache Hop](https://hop.apache.org).  

Feel free to suggest any improvements and to file issues by the plugin issue tracker.

## How to install

### System Requirements

[Apache Hop](https://hop.apache.org) 2.15 or above.

### Manual Install

1. Copy the plugin archive in [Apache Hop](https://hop.apache.org) root folder and unzip it
2. Restart Hop
